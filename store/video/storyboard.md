# HabHub store-video storyboard

The generated masters use real release-candidate app screens from the synthetic
demo profile. The only added elements are fixed captions, HabHub brand
backgrounds, crops, and short fade-to-brand transitions. There are no invented
feature mockups, Android widget scenes, or native photo-video-export claims.

## Google master — 44.9 seconds

The Google cut uses the same truthful 13-beat sequence at 3.45 seconds per beat,
giving each caption and app screen more reading time. It intentionally excludes
Android widget, background-sync, notification-tap, and native video-export
scenes until those features pass signed-device validation.

## Production rules

- Every feature panel must remain traceable to a real app capture.
- Keep captions understandable without audio.
- Use only synthetic names, entries, meals, and progress imagery.
- Avoid calorie, weight-loss, body-shape, health-sync, or AI outcome guarantees.
- Rebuild and revalidate after replacing a source capture.
- Treat the Apple file as a master until App Store Connect accepts it for the
  exact selected device class.
